# fignya

OSS desktop-аналог Figma, где дизайн — живой HTML/CSS; импорт `.fig`, offline, локальный ИИ.
Контекст и решения — `.context/` (карта в `.context/README.md`). Сейчас в репо только спайки
(`spikes/`), у каждого свой README с командами.

Эталон Figma у пользователя просить ссылкой на ноду (`https://www.figma.com/design/<ключ файла>/…?node-id=12645-43534`)
плюс путь «страница / фрейм», не голым id: по номеру ноду он не находит. Ключ файла — в памяти проекта; нет — спросить.
