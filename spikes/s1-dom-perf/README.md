# S1 — DOM perf: Chromium (Electron) vs WKWebView (Tauri)

Выбрасываемый спайк. Вопрос: выдерживает ли живой DOM экраны реального `.fig` и чем
отличаются Electron и Tauri по первой отрисовке, FPS pan/zoom и RSS.

## Что делает

1. `build` — `.fig` (ZIP → `canvas.fig` → kiwi) → дерево узлов с раскрытием инстансов → спека DOM.
   Сценарии: экраны p50 / p99 / max по числу DOM-элементов и обзор самой населённой страницы
   миниатюрами. Всё пишется в `dist/` (в git не попадает — там приватный контент).
2. `thumbs` — Electron offscreen растеризует экраны обзора в PNG (scale 0.25).
3. `bench` — для каждого сценария × {без will-change, `?wc=1`} × рантайм × REPS запускает
   приложение, страница сама меряет и шлёт отчёт на `fignya://localhost/__report`, раннер снимает RSS.

Оба хоста грузят одни и те же файлы через кастомную схему `fignya://` с диска.

## Метрики

| Метрика | Как |
|---|---|
| first frame | `performance.now()` от парсинга JSON-сцены до второго rAF после вставки DOM |
| +images | до `decode()` всех картинок |
| pan / zoom fps, p95 | дельты rAF за 3 с анимации `transform` на `#world` |
| janky | кадры длиннее 1.5 × vsync (vsync = медиана rAF в простое) |
| RSS | `ps` по дереву процессов хоста; для Tauri + `com.apple.WebKit.*`, стартовавшие после запуска |

## Прогон (руками, на живом маке)

Окна не перекрывать и не сворачивать во время прогона: скрытое окно глушит rAF.
Питание от сети, Low Power Mode выключен: иначе WebKit режет rAF до 30 fps (vsync 33 мс),
Chromium — нет, и сравнение теряет смысл. Раннер печатает `WARNING …`, если условие нарушено.

```nu
cd ~/_dev/fignya/spikes/s1-dom-perf
bun install
with-env { FIG_FILE: ("~/Downloads/ROI Navigator.fig" | path expand) } { bun run build:all }
bun run bench
```

`with-env { REPS: 1 } { bun run bench }` — быстрый прогон, `RUNTIMES: tauri` — один рантайм.

## Ожидаемый вывод

Без строк `WARNING …` в начале. Строка на каждый запуск (`rep 1 electron screen-p50.html RSS … MB`), затем таблица медиан
`page | runtime | DOM | first frame | … | RSS` и путь к `results/<stamp>.json`. Таблица также
пишется в `results/<stamp>.md`. Строки `FAILED …` — страница упала, текст ошибки рядом.

## Ограничения спайка

- Оверрайды инстансов не применяются (тексты — из мастер-компонента), размер инстанса не
  пересчитывает детей символа.
- Скрытые в символе слои пропускаются, хотя оверрайд мог их включить → DOM может быть занижен.
- Градиенты приблизительные, stroke — `box-shadow inset` / `outline`, эффекты — только тени и blur.
- rAF-дельты не видят пропуски композитора; WKWebView может держать 60 Гц на 120 Гц дисплее —
  смотреть колонку vsync.
