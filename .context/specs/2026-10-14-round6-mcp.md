# Спецификация: раунд 6 — ИИ-агент через MCP поверх Command API

Интервью 26-10-14 (`/spec-interview`). Последний пакет вопросов (обводка, нарезка, финал) пользователь пропустил —
по ним взяты рекомендованные варианты, помечены «(по умолчанию)».

## Контекст

Command API сейчас: `Edit { target: NodeId[]; style?: StylePatch (12 ключей); text? }`, undo/redo по одной правке (лимит
200), поиск, модель экрана, save в sidecar. Документ живёт в importer (`utilityProcess`), окно одно, документ один.
Модель экрана в JSON p50 682 КБ (~200k токенов) — отдавать агенту целиком нельзя. Своего LLM-рантайма нет.

Нарезка (решение пользователя 26-10-14): **6.1** — MCP-сервер на текущих 12 ключах, отдельной сессией; **6.2** — видимость
и обводка в Command API и инспекторе. Схема `apply_edits` строится из `EDIT_KEYS`, поэтому ключи 6.2 доходят до агента без
правок сервера. Каждый срез — свой T3, ревью, заметка `notes/round6-*.md`.

## Требования

### Функциональные

6.2 — Command API и инспектор:
- `Edit.hidden?: boolean`; инспектор — переключатель видимости. Скрытый слой остаётся выделенным до снятия выделения.
- Обводка (по умолчанию — поле модели): `Style.stroke?: { width: Px; color: Color; align: "inside" | "center" | "outside" }`
  для равномерной обводки не-векторов. Импорт пишет его вместо `outline` / inset-тени со spread; `css-text` выводит
  тот же CSS, что сейчас. Независимые стороны и векторы — как были, в инспекторе только чтение.
- Редактируемые ключи: 12 прежних + `stroke` + `hidden` (агенту — автоматически через `EDIT_KEYS`). Undo/redo, sidecar, миниатюры — как у прежних ключей.

6.1 — MCP:
- Streamable HTTP на `127.0.0.1` из main, официальный `@modelcontextprotocol/sdk` (зависимость только main).
- Выключен по умолчанию. Меню: «Enable MCP Server» (флажок, запоминается), «Copy Claude Code Command»
  (`claude mcp add --transport http fignya http://127.0.0.1:<port>/mcp --header "Authorization: Bearer <token>"`),
  «Reset MCP Token». Токен — 32 байта hex в `userData/mcp.json` (0600).
- Инструменты:
  - чтение: `document` (страницы, экраны, открытый экран), `outline` (экран или поддерево, лимит ответа),
    `inspect` (адрес → CSS-декларации + текущие редактируемые значения), `search`, `selection`,
    `screenshot` (экран или узел → PNG);
  - правка: `apply_edits({ edits, affectsInstances? })`, `undo_agent_edit()`;
  - UI: `open_screen(screenId)`, `select(address)`.
- Конспект: узел — строка (адрес, имя, тип, бокс, текст); инстанс свёрнут (компонент/вариант, тексты внутри),
  раскрытие — `outline` по адресу инстанса; скрытые слои не показываются; лимит узлов на ответ, хвост «… ещё N».
- Значения стиля — CSS-строки (`"#ff6600"`, `"8px 16px"`, `"1px solid #000"`), парсер полей инспектора (`css-input`).
- Пачка = один шаг истории; всё или ничего: валидация всей пачки до применения, ошибка — индекс правки + причина.
- Правка узла мейн-компонента отклоняется с числом затронутых инстансов, пока нет `affectsInstances: true`.
- `undo_agent_edit` откатывает пачку агента, только если она на вершине истории; иначе ошибка «сверху правка
  пользователя». Redo агенту не нужен. Save у агента нет — сохраняет пользователь ⌘S.
- Клиент, обязательный для T3, — Claude Code; остальные — по стандарту, без гарантий.

### Нефункциональные

- Ответ `outline` ≤ ~8k токенов по умолчанию; PNG по длинной стороне ≤ 1568 px.
- `apply_edits` на 50 правок — без заметной паузы UI (importer обрабатывает квантом, как прочие запросы).
- CSS неправленых экранов после 6.2 байт-в-байт тот же (кэш миниатюр остаётся валидным).
- Без сети: сервер слушает только loopback; ничего не уходит наружу.

## Архитектура

```
Claude Code ──HTTP+Bearer──▶ main/mcp/ (SDK server, auth, tools)
                               ├─ чтение/правка ─▶ import-client ─▶ importer (EditSession, NodeMap)
                               ├─ screenshot ────▶ thumb-renderer (offscreen)
                               └─ UI ────────────▶ renderer (open/select, подсветка, индикатор)
```

- `main/mcp/`: сервер, проверка Host (`127.0.0.1:<port>`, `localhost:<port>`), отказ при заголовке `Origin`,
  Bearer-токен, лог; инструменты — по файлу на инструмент.
- importer: новые запросы `outline`, `inspect`, `batch` (Edit[] + origin); `EditHistory` — шаг = набор записей
  `{ edits, origin: "user" | "agent", entries }`, лимит 200 считает шаги.
- Порт по умолчанию фиксированный, переопределение `FIGNYA_MCP_PORT`; занят — диалог, сервер выключен.
- Лог: `userData/logs/mcp.log`, ротация 5 МБ × 1; время, инструмент, адреса, результат/ошибка, мс, размер ответа —
  без текстов и значений стиля.

## API / Интерфейсы

- Адрес узла — строка `id/id/…` = `Edit.target` (цепочка от внешнего инстанса).
- `apply_edits.edits[]`: `{ target: string; style?: Record<EditKey, string>; text?: string; hidden?: boolean }` (`hidden` — с 6.2).
- Ответ `apply_edits`: `{ step, changed: string[], screens: string[] }`; ошибка — `{ index, reason }`.
- Протокол importer: `{ type: "batch"; reqId; edits: Edit[]; origin: "agent" }` → `edited` с `change[]`.

## UI/UX

- Индикатор «агент подключён» в тулбаре, пока есть MCP-сессия.
- Изменённые агентом узлы на живом экране подсвечиваются ~1 с.
- Меню Edit: «Undo Agent Edit», когда на вершине истории пачка агента; ⌘Z откатывает её целиком.
- Правка агента во время Play применяется, Play показывает её со следующего рендера экрана.

## Edge Cases

- Документ не открыт или грузится → ошибка инструмента «нет документа / идёт импорт».
- Неверный адрес (нет узла по цепочке) → ошибка валидации, пачка не применяется.
- Пользователь правит тот же узел одновременно → очередь importer, последняя побеждает; ответ агенту — итоговое значение.
- Скрыли выделенный слой и сняли выделение → вернуть через undo или поиск ⌘F (находит скрытые).
- Агент шлёт ключ вне редактируемых или `text` не у TEXT → вся пачка отклонена.
- Окно закрыто с несохранёнными правками агента → обычный Save / Don't Save / Cancel.
- Второй экземпляр приложения → порт занят, сервер второго выключен.

## Риски и митигации

| Риск | Вероятность | Митигация |
|------|-------------|-----------|
| Локальный процесс/страница браузера правит документ | средняя | выкл по умолчанию, Bearer, Host-проверка, отказ при `Origin` |
| Конспект не влезает в контекст агента | высокая | свёрнутые инстансы, лимит + «… ещё N», раскрытие по адресу |
| Агент перекрашивает компонент и тысячи инстансов | средняя | флаг `affectsInstances`, число инстансов в ошибке, undo пачкой |
| `stroke` в модели меняет CSS импортированных экранов | средняя | тест паритета CSS на 408 экранах ROI до/после |
| Undo агента откатывает правку пользователя | низкая | только своя пачка на вершине |
| Спека MCP меняется | средняя | официальный SDK, версия зафиксирована |
