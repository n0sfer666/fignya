# Конвенции

- TypeScript strict + `noUncheckedIndexedAccess`; без `any`, `as`, `@ts-ignore`. Нетипизированные
  данные (kiwi, JSON) — `unknown` + гарды из `src/fig/guards.ts` (`isRec`, `num`, `str`, `recs`…).
- Одна ответственность на файл, ≤ 200 строк. Без комментариев в коде.
- Функции-стрелки, именованные экспорты, без классов там, где хватает функций.
- Конвертер читает новое поле сырого узла → добавить его в `fig-import/src/fig/kept-fields.ts`,
  стилевое — в `STYLE_FIELDS` (общий для узла и оверрайда), вложенное — в дерево `Shape` (`nested`),
  иначе потоковый импорт его отбросит. Эквивалентность со старым
  путём проверяет тест `import-steps.test.ts` только на синтетике.
- Большой буфер в генератор параметром не передавать: V8 держит параметры завершённого генератора,
  пока жив сам объект (локальные — отпускает). Передавать через `takeOnce` (`fig-import/src/take-once.ts`).
- Замыкания одного вызова функции делят один контекст V8: ленивый геттер, созданный рядом с сырым
  узлом, держит его вечно — строить геттер в отдельной функции (`instanceNode` в `convert-node.ts`).
  Обход всех узлов модели с чтением `overrides` резолвит весь файл.
- Приватные данные (`.fig`, картинки из него, имена экранов) — никогда в git; путь к `.fig` — env `FIG_FILE`.
- IPC: контракт main ↔ renderer типизирован в `apps/desktop/shared/api.ts`; данные от своего main
  гардами не проверяются: `ipcRenderer.invoke`/`on` в preload — доверенная граница, их `any`
  сужается типом `FignyaApi`. Входы main от renderer (id экрана, URL протокола, запрос шрифтов —
  `main/font-request-guards.ts`) — `unknown` и проверка;
  отправитель — `isAppUrl(senderFrame.url)`.
- Main ↔ importer: контракт в `apps/desktop/importer/protocol.ts`, сообщения — `unknown` + гарды
  `importer/protocol-guards.ts` (дискриминатор и поля верхнего уровня). На каждый запрос с `reqId`
  importer отвечает всегда — значением или `refused`, иначе промис в main повиснет.
- Всё, что main пишет в `userData`, — только в своём подкаталоге (`thumbs/`, `fonts/`); удаление —
  лишь по маске своих имён, рядом лежат служебные каталоги Electron.
