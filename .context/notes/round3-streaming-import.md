# Раунд 3 — потоковый импорт (статус: реализовано, ревью пройдено, ждёт T3 пользователя)

Фидбек T3: при загрузке реального `.fig` ~6 с крутится колёсико macOS, съедается память.

## Замер до (V8, реальный файл 170 МБ, 360 637 узлов)

decode 4.3 с → heap 2.6 ГБ (сырое kiwi-сообщение); convert 2.8 с; модель без сырья — heap 0.3 ГБ.
max RSS 2.5 ГБ, peak footprint 4.2 ГБ. Колёсико — main занят импортом целиком.

## Решение

- Импорт в `utilityProcess` (`apps/desktop/importer/`); модель и картинки живут там, main держит
  только страницы и проксирует `screen`/`image` запросами (`main/import-client.ts`,
  `main/pending-requests.ts`; смерть процесса отклоняет ожидающие и будущие запросы).
- Потоковый kiwi (`fig/read-message.ts`, `fig/kiwi-decoder.ts`) + allowlist полей узла
  (`fig/kept-fields.ts`) с вложенным slim `symbolData`/`textData`.
- `importSteps(archive)` — генератор с `ImportProgress` каждые 500 узлов; принимает уже распакованный
  архив, чтобы буфер файла (170 МБ) не жил весь импорт. `importFig` = синхронный прогон.
- Конвертация — итеративный DFS (`tree/placements.ts`) вместо рекурсии.
- Importer гонит шаги квантами `IMPORT_PACE` 20 мс работы / 20 мс паузы (`importer/paced.ts`).
- Прогресс: `document:progress` → `<progress>` с % (`renderer/src/import-status.tsx`).

## Замер после

| | до | после |
|---|---|---|
| bench (Node) max RSS | 2530 МБ | 1580–2050 МБ (зависит от давления памяти в системе) |
| bench время | ~7.1 с | 5.3–6.6 с |
| Electron main RSS во время импорта | ~2.5 ГБ, поток занят | ~140 МБ, CPU ~0% |
| Electron importer пик RSS (сэмплы ps) | — | 820–1070 МБ |
| Время импорта в окне | ~6.5 с | 7.2–7.5 с (темп 20/20; при 30/10 — 5.6 с) |

Эквивалентность на реальном файле: 360 637 узлов, 0 отсутствующих, 0 отличий, страницы равны.

Не помогло: явный GC каждые N батчей (x3 время), `--max-old-space-size`, `--max-semi-space-size`,
`--single-threaded-gc` через `execArgv` (CPU importer всё равно 100–230% в пиках — потоки V8).

## Ревью (code-reviewer: 2 medium, 12 low — исправлены)

- Importer отвечает на каждый `screen`/`image` значением или `refused` (раньше исключение вешало
  очередь миниатюр); протокол — `unknown` + гарды; `failed` убивает процесс; падение importer после
  `ready` → `document:lost` → красная надпись в окне.
- Тест `kept-fields.test.ts`: насыщенная фикстура, slim-путь = полный путь; мутационно проверено —
  удаление любого из 40 полей allowlist роняет тест.
- Буфер `canvas.fig` больше не живёт в фазе convert (`takeOnce`, см. conventions).
