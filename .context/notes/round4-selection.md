## Структура

```
packages/render-dom/src/rendered-node.ts  WeakMap<Element, RenderedNode>: итоговая нода (оверрайды + подгонка
                                          под ресайз) и компонент инстанса; пишет render-node, читает renderer
packages/model/src/inspect.ts             inspect(node, component, imageUrl) → шапка Layer + секции
                                          CSS-деклараций (cssDeclarations), секция — по имени свойства
apps/desktop/renderer/src/
  canvas/double-click.ts   второй клик в пределах 500 мс и CLICK_SLOP
  canvas/hit-node.ts       composedPath события → самый глубокий [data-id] в shadow root живого экрана
  canvas/pick.ts           цепочка [data-id] от корня экрана; click / inner (двойной) / deep (⌘)
  canvas/outline-box.ts    рамка в координатах кадра + ResizeObserver/loadingdone (вынесено из node-mark)
  canvas/live-selection.ts выделение и hover живого экрана, onSelect наружу
  inspector.tsx            панель справа: Layer + секции; пусто — подсказка
```

Правила выбора (цепочка `[корень, a1, …, hit]`, выделение `S` с цепочкой `C`):
- клик: общий префикс цепочки с `C` до родителя `S` (без выделения — корень) → следующий элемент цепочки
  (свой уровень или сосед `S`; клик по фону корня — корень);
- двойной клик: `S` в цепочке → её ребёнок под курсором, иначе как клик;
- ⌘+клик: `hit`;
- hover показывает то, что выберет клик с теми же модификаторами;
- Esc: есть выделение — снять, нет — закрыть живой экран; клик мимо живого экрана по пустому холсту — снять.
- Поиск ⌘F выделяет найденную ноду (одна синяя рамка вместо отдельной node-mark), инспектор её показывает.
